# Challenger frame sources (local prototype, 2026-10-24)

Riot Games owns the League of Legends artwork. CommunityDragon hosts extracted client assets; it is not Riot's official distribution site.

- Reference supplied by user: https://www.9game.cn/lolsy/8957570.html (S12 ranked frames, Challenger example).
- Original transparent wings and ring: https://raw.communitydragon.org/latest/plugins/rcp-fe-lol-static-assets/global/default/ranked-emblem/wings/wings_challenger.png
- Original client reveal animation, including embedded metal textures: https://raw.communitydragon.org/latest/plugins/rcp-fe-lol-static-assets/global/default/lottie/ranked/ranked-wing-challenger.json
- Original reveal: 30 fps, 11 frames. Playback slowed to 0.65x on this prototype; web-only fade/energy breathing complements the original reveal. This is not a claim of an exact client animation recreation.
- Lottie-web 5.12.2, MIT, self-hosted, license in static/vendor/lottie-LICENSE.md: https://github.com/airbnb/lottie-web

Artwork is used unchanged; positioning/cropping is CSS. No image from the reference article was copied into the website. No remote runtime dependency; all website assets are served locally. Publication authorized by the site owner after local review.
